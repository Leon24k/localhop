Built for the Hot Path

          
Everything you need for local development, without SaaS friction.

          

            Engineered in pure Rust with Tokio, Axum, and Hyper. No garbage-collector pauses, no interstitial warning screens, and no arbitrary monthly request caps.
          

        


        

          

            

              
            

            
Zero-Copy Binary Multiplexing

            
All concurrent HTTP requests and responses fly over a single persistent WebSocket using 9-byte binary headers and raw Bytes payloads.

          


          

            

              
            

            
Live Inspector & Offline Replay

            
Stream headers, pretty JSON, and microsecond latency via SSE on port 4040. Edit and replay webhooks in one click, or export JSON fixtures for offline testing.

          


          

            

              
            

            
Full WebSocket Passthrough

            
Vite HMR, Next.js Fast Refresh, Socket.IO, and custom binary or text WebSocket apps work transparently through the tunnel.

          


          

            

              
            

            
Hardened for Public Relays

            
Constant-time token and edge Basic Auth checks, configurable tunnel and body-size caps, idle zombie tunnel eviction, and localhost CSRF protection.

          


          

            

              
            

            
Free Single-Port Hosting

            
Deploys to Render free tier or any container host with one port. Supports instant path routing (/t/<id>) or wildcard subdomains (*.yourdomain.com).

          


          

            

              
            

            
Auto-Reconnect & Live RTT

            
Exponential backoff reconnects cleanly across sleep or spot restarts while periodic Ping/Pong frames track live tunnel round-trip latency.

60-Second Setup

          
From clone to public URL in three commands.

          

            Run everything locally to test, or deploy your private relay on Render's free tier using the included Blueprint.
          

        


        

          

            1
            
Start or Deploy the Relay

            
Run locally with Cargo, or click New Blueprint on Render with the included render.yaml.

            
cargo run --release -p localhop-server

          


          

            2
            
Expose Your Local Port

            
Point localhop at any local server (Next.js, Vite, Axum, FastAPI, Rails) with optional Basic Auth.

            
localhop 3000 -s demo --basic-auth dev:secret

          


          

            3
            
Inspect & Replay Live

            
Open the built-in inspector to view payloads, edit headers, copy cURL, or replay webhooks offline.

            
open http://127.0.0.1:4040
